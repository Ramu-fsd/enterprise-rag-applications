# Repository Maintenance Roadmap

Suggested future improvements:

- Add CI validation for all Maven projects.
- Pin and periodically review framework and model-provider versions.
- Add integration-test profiles using disposable infrastructure.
- Add a shared evaluation dataset and reproducible benchmark reports.
- Add architecture decision records for major design choices.
- Add threat models for ingestion, retrieval, model calls and tool execution.
- Add OpenTelemetry tracing and cost instrumentation to integrated services.
- Add deployment overlays for local Docker and OpenShift environments.

Track implementation status honestly in each project's README.
