# Contributing

Thank you for your interest in this repository.

## Contribution guidelines

1. Keep each project self-contained and aligned with its stated learning objective.
2. Prefer Java 21 and Maven for Java examples unless a project documents a different requirement.
3. Include a clear README with prerequisites, configuration, run instructions and limitations.
4. Add tests for business logic and important security boundaries.
5. Never commit API keys, credentials, private certificates, customer data or confidential documents.
6. Document architecture decisions and meaningful trade-offs.
7. Keep examples reproducible and identify any external services they require.

## Pull request checklist

- [ ] Scope and design are explained.
- [ ] Tests are added or updated.
- [ ] Build and test commands are documented.
- [ ] Secrets and sensitive data are excluded.
- [ ] Tenant and access-control implications are reviewed where relevant.
- [ ] README and architecture documentation are updated.
